# Сесія

Україномовний тренажер для підготовки до іспитів. Оберіть тему, складіть короткий підхід на 5, 10 або 20 питань і порівняйте свої відповіді зі зразками. Заняття можна призупинити та продовжити в тому самому браузері.

## Запуск

Потрібен Python 3.10 або новіший. З каталогу проєкту виконайте:

```sh
python3 app.py
```

Відкрийте [Сесію на своєму комп’ютері](http://127.0.0.1:8095). Під час першого запуску застосунок створить базу SQLite з трьома демонстраційними предметами та десятьма картками.

## Як займатися

- **Практика.** Знайдіть тему за назвою або текстом питання. Для самоперевірки відкрийте відповідь та оцініть, чи вдалося її згадати.
- **Пробний іспит.** У додаткових режимах можна пройти до 20 питань за 30 хвилин, повторити складні теми або зібрати білет.
- **Картки.** Повторюйте матеріал за інтервалами або додавайте власні картки у форматі `питання :: відповідь`.
- **Офлайн.** Збережіть вибірку як HTML. Після заняття експортуйте відповіді та імпортуйте файл у вебзастосунок.
- **Планування.** У розділах «Сьогодні», «Предмети», «Борги» й «Матеріали» зібрані завдання, дати іспитів та джерела для підготовки.

## Дані та налаштування

Картки, оцінки повторень і завдання зберігаються у SQLite. Поточний підхід, черга офлайн-відповідей, нотатки до питань і прикріплені зображення зберігаються в браузері.

| Змінна | Призначення | Типове значення |
| --- | --- | --- |
| `SP_HOST` | Адреса для прослуховування | `127.0.0.1` |
| `SP_PORT` | Порт сервера | `8095` |
| `SP_DB` | Шлях до SQLite | `data.db` біля застосунку |
| `SP_FILES` | Каталог матеріалів, доступних через сайт | `materials/` біля застосунку |

Стартові предмети та дати задаються у `seed.json`, приклади карток — у `cards.json`. Застосунок читає їх під час створення бази. Для роботи достатньо стандартної бібліотеки Python. Для відображення математичних формул браузер завантажує KaTeX із CDN.

Сервер розрахований на особисте використання. Для віддаленого доступу використовуйте приватну мережу або проксі з автентифікацією.

## Іспит та облік

У вкладці **Іспит** оберіть демонстраційний білет або потренуйтеся на окремій задачі з покроковим розв’язанням. Після завершення білета можна звірити відповіді, виставити бали та зберегти спробу. Доступні генератори з фізики, хімії та математики, аналіз помилок і план підготовки за внесеними датами іспитів.

У вкладці **Облік** можна записувати оцінки та пропуски, відмічати відпрацювання й налаштовувати співвідношення поточного контролю та іспиту. Особисті записи зберігаються у вашій базі SQLite. У комплекті є два навчальні білети у файлі `tickets.json`.

Щоб додати картку з термінала під час роботи сервера:

```sh
echo 'Чому дорівнює похідна x²? :: 2x' | python3 add_cards.py math
```

Для сервера на іншій адресі задайте змінну `SP_URL`. Повторний імпорт того самого питання з тим самим предметом і джерелом оновлює картку.
